# 🏦 ATM Machine Simulation (Java Swing) ![Build Status](https://img.shields.io/badge/status-active-brightgreen)

A fully functional **ATM Machine Simulation** built using **Java Swing** with a graphical user interface.  
This project enables users to **register, log in, check balance, deposit, withdraw, transfer money, change PIN,** and **view transaction history.**

🔗 **Repository:** [ATM Machine Simulation](https://github.com/GamerBhushan/ATM_Machine_Simulation.git)

---

## 🚀 Features

✅ **User Authentication** (Sign Up & Login)  
✅ **Balance Inquiry**  
✅ **Deposit & Withdrawal**  
✅ **Bank Transfer**  
✅ **PIN Change**  
✅ **Transaction History**  
✅ **Admin Panel to Show All Users**

---

## 🛠️ Tech Stack

- **Java JDK 23**
- **Swing GUI**
- **SQLite Database**
- **IntelliJ IDEA** (Development Environment)
